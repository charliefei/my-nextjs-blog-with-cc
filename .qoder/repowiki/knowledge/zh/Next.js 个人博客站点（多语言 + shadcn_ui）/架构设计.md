根目录作为 Next.js 应用入口，将子模块按职责分层串联：
- 路由层 `app/[locale]/` 通过 `i18n/routing.ts` 与 `messages/*.json` 驱动多语言页面，页面组件从 `components/` 拉取 UI，再调用 `lib/posts.ts`、`lib/experience.ts`、`lib/about.ts` 等读取 `content/` 下的 Markdown/JSON。
- `lib/markdown.tsx` 统一使用 `remark`/`rehype` 处理内容，`lib/toc.ts`、`lib/highlight.ts`、`lib/rss.ts`、`lib/seo.ts` 提供跨页面共享能力；`types/` 与 `lib/site.ts` 定义全站类型与配置，被各 page 与 component 共同消费。
- `components.json` 驱动 shadcn/ui 的原子组件生成，`components/theme/theme-provider.tsx` 配合 `next.config.ts` 的 CSS 变量实现主题切换。
- 构建期由 `scripts/` 在 `next build --output=dist` 后对 `out/` 执行 SEO 修复、RSC 路径扁平化与图片压缩；`docker/` 复用同一产物，用 Nginx 托管静态文件并注入缓存头。
- 顶层 `package.json` 是唯一的脚本编排点，聚合 dev/build/export/deploy 命令，供本地开发、CI 与 Docker 构建共用。
