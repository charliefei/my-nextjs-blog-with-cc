本模块是纯声明式部署产物，不包含运行时代码，由四个文件构成完整的容器化流水线：
- `Dockerfile` 采用两阶段构建：`node:20-alpine` 作为 builder 执行 `npm ci` + `npm run build`（生成到 `/app/out`），再以 `nginx:alpine` 为运行时镜像，仅拷贝 `out/` 静态资源与自定义 `nginx.conf`，并通过 HEALTHCHECK 探测 80 端口。
- `docker-compose.yml` 将构建上下文指向项目根目录（`context: ..`），通过 `dockerfile: docker/Dockerfile` 指定当前目录的 Dockerfile，默认映射宿主机 3000 → 容器 80，并预留了挂载自定义 nginx.conf 的卷注释示例。
- `nginx.conf` 针对 Next.js 静态导出做了专项优化：对 `/_next/static/` 设置一年 immutable 缓存、HTML 页面 1h must-revalidate、字体与图片 30d 缓存；通过 `rewrite ^/([^.]*[^/])$ /$1/ permanent;` 强制尾部斜杠路由约定，并用 `try_files $uri $uri/index.html /404.html` 实现 SPA 回退；同时附加 X-Frame-Options、X-Content-Type-Options、Referrer-Policy 等安全头，并拒绝访问隐藏文件。
- `.dockerignore` 排除 `node_modules`、`.next`、`out/`、`.git`、`.env*`、`docker/` 自身以及文档与 IDE 文件，确保构建上下文最小化。
