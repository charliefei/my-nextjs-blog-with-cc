- 所有需要静态生成的 Route Handler (`rss.xml`, `llms.txt`, `llms-full.txt`) 都显式设置 `export const dynamic = "force-static"` 以走构建期生成。
- 国际化页面统一在 `generateMetadata` 中调用 `buildPageMetadata({ locale, path, title, description })` 组合 SEO 元信息，而非手写 Metadata 对象。
- 多语言路由通过 `@/i18n/routing` 的 `locales` 数组驱动，在 `generateStaticParams`、`sitemap.ts`、`robots.ts` 等处复用同一来源，避免硬编码语言列表。
- 所有对外 URL 一律经 `@/lib/site` 的 `getSiteUrl` / `getAbsoluteUrl` 包装，禁止直接写裸路径字符串。
- 服务端组件通过 `params: Promise<{ locale: string }>` 异步解构 locale，并在首行调用 `setRequestLocale(locale)` 激活 next-intl 上下文。
