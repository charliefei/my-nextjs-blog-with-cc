- 所有客户端组件在文件首行显式标注 `'use client'`，服务端渲染组件则省略该指令。
- UI 原子组件统一通过 `cva` 声明 `variant`/`size` 等变体，并以 `VariantProps<typeof xxxVariants>` 推导 Props 类型，再通过 `cn(buttonVariants({ variant, size, className }))` 拼接样式。
- 多语言文案一律通过 `useTranslations('xxx')` 获取，模板字符串中直接调用 `t(key)`，禁止硬编码可见文本。
- 路由链接统一以 `/${locale}${href}` 形式拼接，并借助 `useLocale()` 与 `usePathname()` 进行 active 状态判定。
- 样式类名统一经 `@/lib/utils` 的 `cn` 函数合并，避免直接使用原生 `clsx` 或模板字符串拼接。
