模块按职责划分为四层：
- `components/ui/`：原子级可复用 UI 控件（Button、Badge、Card、Dialog、Sheet、DropdownMenu、NavigationMenu、ScrollArea、Separator、Skeleton、Tooltip、Input、Avatar），均通过 `@base-ui/react` 作为无样式基元，使用 `class-variance-authority` 的 `cva` 声明 variant/size 变体，并通过 `@/lib/utils` 的 `cn` 合并 className；全部标注 `'use client'`。
- `components/theme/`：主题能力封装，`theme-provider.tsx` 仅对 `next-themes` 的 `ThemeProvider` 做薄包装，`theme-toggle.tsx` 暴露切换开关供 Header 消费。
- `components/layout/`：全局布局壳层，`header.tsx` 组合 Sheet 移动端抽屉导航、`language-switcher.tsx` 与 `locale-redirect.tsx` 处理 next-intl 多语言路由前缀，`footer.tsx` 承载底部信息。
- `components/{about,blog,comments,experience,home,resume}/`：按内容域划分的页面级复合组件，各自聚合 ui 层与第三方集成（如 `giscus-comments.tsx` 对接 Giscus 评论、`reading-progress.tsx` 与 `toc.tsx` 配合 MDX 阅读体验）。
依赖方向单向向下：业务组件 → layout → theme/ui → `@/lib/*` 工具与类型，不反向引用。
