- 每个内容域（post/experience/about/link/profile）采用「frontmatter 接口 + 扩展实体接口」成对声明在 `types/`，并在同名 `lib/*.ts` 中通过 fs 读取对应目录的 Markdown 文件组装实体。
- 所有对外 URL 统一经 `getSiteUrl` / `getAbsoluteUrl` 生成，资源路径经 `getAssetPath` 处理，避免在各处重复拼接 basePath。
- Locale 相关函数以 `(typeof routing.locales)[number]` 作为类型约束，保证 locale 值与 i18n 路由同步。
- 面向客户端的 React 组件在文件首行显式标注 `"use client"`，纯函数工具保持无副作用可被服务端/客户端同时 import。
