本模块为纯数据层，不包含任何业务逻辑代码，由上层 Next.js 应用通过文件系统读取：
- `content/config/`：全局配置（`profile.json` 含个人简介、社交链接、评论 giscus 参数与主题色；`about.*.md` 提供 About 页的富文本）。
- `content/experience/`：按子域划分——`projects/` 与 `work/` 下各语言用同名 `.md` 描述项目与工作；`skills/` 使用结构化 JSON 数组按 category 分组技能条目。
- `content/posts/{en,zh}/`：每篇博文一个带 YAML front-matter（title/description/date/tags/category/slug/published 等）的 Markdown 文件，按语言分目录存放。
- `content/links/links.json`：友链列表，供 About 页面渲染。
- `messages/{en,zh}.json`：与页面路由一一对应的 i18n 键值表（nav/home/blog/about/resume/experience/footer/theme/lang/notFound/metadata），作为 UI 文案的唯一来源。

依赖方向单向：上层组件 → 读取本模块文件 → 渲染视图；本模块不反向依赖任何源码。新增语言只需在对应目录创建同名字节级文件即可。
