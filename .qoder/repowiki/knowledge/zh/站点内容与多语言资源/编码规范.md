- 所有面向用户的可本地化文案统一收口到 `messages/{lang}.json`，模板中不得硬编码字符串。
- 多语言内容采用 `{lang}` 子目录 + 同名文件的镜像结构（如 `posts/en/*.md` / `posts/zh/*.md`、`experience/projects/en/*` / `experience/projects/zh/*`）。
- Markdown 博文统一以 YAML front-matter 声明元数据（title/description/date/tags/category/slug/published），正文仅承载富文本。
- 结构化清单类数据（skills、links）使用 JSON 数组并按语义字段组织（category/name/level/description/url 等），而非分散在多个文件中。
